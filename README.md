## 📚 Project Summary

**CppLabs** contains my weekly lab exercises from the C++ programming course at İstinye University. It covers the fundamentals of the language, from basic input/output and control flow to functions, arrays, strings, searching and sorting, exception handling and pointers.

The object-oriented part of the course is in [OopLabs](https://github.com/exhilarin/OopLabs).

---

## 🧠 What I Learned in CppLabs

| Week | Topic | Exercises |
|---|---|---|
| **01** | Input / Output | Reading values with `cin`, printing with `cout`, circle area calculation |
| **02** | Conditionals | `if` / `else`, string comparison, `switch` |
| **03** | Loops | `for`, `while`, `do-while` (sum of even numbers, password check) |
| **04** | Functions | Pass by value vs **pass by reference**, default arguments, **recursion** |
| **05** | Arrays | 1D arrays, arrays of strings, 2D arrays (3×3 matrix) |
| **06** | Strings | C-style strings with `cin.getline`, `std::string` and `getline` |
| **07** | Searching & Sorting | **Bubble sort**, **binary search** |
| **08** | Exception Handling | `try` / `catch` / `throw` (division by zero, invalid index, invalid input) |
| **09** | Pointers | Addresses, dereferencing, pointer arithmetic on arrays, strings via pointers |
